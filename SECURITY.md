# Security and privacy

This repository contains a portfolio lab built with fictitious medical data only.

Do not commit:

- Azure subscription or tenant IDs
- Microsoft Entra object IDs
- Email addresses or personal account information
- Public IP addresses
- Storage keys, SAS tokens, connection strings, or secrets
- Session, request, correlation, or deployment IDs
- Raw Azure Portal screenshots that have not been redacted
- Real medical or personally identifiable information

If sensitive information is committed accidentally, remove it from the repository and rotate any affected credentials or secrets immediately.
